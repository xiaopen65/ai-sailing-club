# AI 航海研习社 · 全面赋能

一个用来展示研习社 AI 方案的静态网站。站内统一叫「方案」，本机文件夹和压缩包仍沿用原来的名字（AI案例库），路径不变。暖白纸感 + 超粗黑标题 + 荧光绿点缀，11 个方案，8 个可以直接在浏览器里试玩，支持浅色 / 深色两套主题。

每个方案的详情里都有一条**迭代路径**：从第一版到现在的功能阶段，做了什么、为什么改。

网站现在有三条成长路线：**学习**（课程库 / 系统地图 / 能力测试）、**赋能**（视野赋能）、**交流**（交换人生）。

## 页面结构

| 页面 | 文件 | 说明 |
|------|------|------|
| 首页 | `index.html` | 品牌入口：Hero + 路线入口 |
| 学习 | `route.html` | 个人学习地图 / 课程库 / 能力测试与海上餐厅入口 |
| 能力测试 | `test.html` | 24 道单题测试：技能 / 思维 / 结果三条线 |

| 交流 | `exchange.html` | 交换人生：成员交换卡、发起交换、短信确认、24 小时未确认冻结 |
| 关于 | `about.html` | 研习社介绍与能力图谱 |

## 怎么打开

**方式一（推荐）**：双击 `打开案例库.bat`。它会启动本地服务，并自动打开 `http://127.0.0.1:8125/`；页面之间的左右滑动过渡、编辑模式保存都正常。

**方式二（直接打开文件）**：双击 `index.html`。能正常浏览、筛选、打开 Demo，页面切换同样有左右滑动效果；只是编辑模式无法把修改写回文件，需要保存时用方式一。

> 想让页面切换有滑动动画，请用方式一。

## 直接改文字（编辑模式）

不用改代码，也不用找人：

1. 双击 `编辑文案.bat`（需要装 Node.js）。
2. 浏览器会自动打开 `http://127.0.0.1:8125/?edit=1`，直接进入编辑模式。
3. 也可以正常打开网站，点右上角 **设置 → 编辑模式 → 进入编辑**，或按 `Ctrl+E`。
4. 直接点页面上的字改；改完点右上角 **完成编辑**。

改动会在 600ms 后自动保存到 `assets/js/edits.js`（`编辑文案.bat` 的窗口保持运行即可）。之后无论是用编辑模式打开，还是直接双击 `index.html`，都会带着这些修改。

- **能改**：页面标题 / 副标题、方案标题 / 摘要 / 详细描述、亮点、迭代路径、关于段落、页脚等。
- **不能改**：按钮、布局、图片、链接地址（这些在 `index.html` / `data.js` / CSS 里；需要加减内容再找我）。
- 右上角设置里的「编辑模式」只在本地（`file://` 或 `localhost`）出现；公开到网上后会自动隐藏，访客看到的是干净版本。
- 直接双击 `index.html` 也能编辑，但只保存在浏览器里，不会写回文件；要写回文件必须用 `编辑文案.bat`。
- 想全部恢复原文案：编辑模式下点右上角「重置」。
- 分享时直接发本地 `备份与归档` 里的 `AI案例库-分享版.zip`；如果重新压缩，排除 `备份与归档` 文件夹，避免把旧备份也打进去。
- 界面亮色 / 暗色也在右上角「设置 → 界面」里切换，会记住选择。

## 文字修改保存在哪

分两层：

1. **浏览器本地缓存（localStorage）**：只存在当前浏览器里。网站文件更新不会让它消失，但清缓存、换浏览器、换电脑就会丢，也不会跟着文件夹发给别人。
2. **`assets/js/edits.js`**：真正的文件，跟网站一起走。用 `编辑文案.bat` 保存时写进去，分享、部署、换设备都会带上。

如果你之前是直接双击 `index.html` 改的，文字很可能只在浏览器缓存里。可以这样搬进文件：

1. 打开**现在这个带修改的页面** → 右上角 **设置 → 文字修改 → 导出**，会下载一个 `AI全面赋能-文字修改.json`。
2. 双击 `编辑文案.bat` 打开网站 → **设置 → 文字修改 → 导入**，选中刚才的 json。
3. 导入后会写进 `edits.js`，以后更新、分享都不会丢。

以后我更新网站时会保留 `edits.js`；如果你自己整体替换文件夹，记得把这个文件一起带上。

> 当前编辑模式覆盖首页 / 赋能 / 关于 / 学习页课程卡、课程库类目文案，以及学习地图的列标题、列说明、层标题、层说明、结果卡标题 / 描述、目标行文字，以及课程弹窗的标题、介绍、示例图片和链接。学习地图的课程行还可以在编辑模式里新增 / 删除 / 用 ↑↓ 上下排序；新增时填写课程名和链接。结果列的 01 / 02 / 03 三张目标卡固定不变，和技能 / 思维一样用 V 按钮逐层展开 / 收回；每张卡展开后是具体目标行，点目标行会打开弹窗，可修改标题、具体内容或删除；卡片本身直接点击展开 / 收回，展开后右上角才出现 + 目标 新增一条目标，不需要编辑模式。设置里可以「生成学习地图」，全部类目展开，按课程和目标显示完成 / 未完成；支持亮 / 暗切换，并可导出一张 PNG。编辑模式去掉了重置，改成「数据备份 → 导出 / 导入」，会一并备份文字修改、课程增删排序、个人目标和完成状态，数据先保存在本机浏览器。学习课程库在 `route.html`，能力测试的问题 / 评分 / 报告在 `assets/js/assessment.js`、`test.js`、`report.js`，交流成员档案在 `assets/js/members.js`；这些内容直接改数据文件即可。

## 页面里有什么

- **Hero**：超粗标题 + 三张悬浮截图。鼠标移动会有视差，截图会缓慢浮动；**点任意一张截图直接打开方案详情**。
- **全面赋能**：11 个方案，可按类别筛选、关键词搜索；卡片会标出「N 阶段」迭代次数。标题下方有一条黑色随机方案滚动视图：点一下按钮，所有方案卡一起滚动，停在中间的那张最大、最立体，点开就是方案详情。
- **方案详情**：点卡片会从卡片位置「弹出」一个大面板——左边看截图或直接运行 Demo，右边看背景、**迭代路径**、亮点与技术栈；左右两侧的圆形箭头可以切换上一个 / 下一个方案。
- **关于**：关于 AI 航海研习社、介绍文章外链，以及一张从下往上的「AI 时代能力分布」图（60% → 30% → 10% → 1% → 0.1%）。
- **个人学习地图**：学习页最上方，技能 / 思维 / 结果三条线；初始只横向展开思维，技能和结果折叠成竖向标签，用向右箭头横向展开，展开后用向左箭头收回。每列各 3 层，初始只有第 1 层；层底部 V 按钮按一次长一层，三层后变成向上箭头，按一次退一层，逐层退回。点击卡片展开课程树，再点一下收起；圆点标记完成；点课程标题会弹出课程卡：标题、课程用处介绍、可下拉的示例（示例支持上传图片）；有链接时显示「开始学习」，没有链接时显示「课程正在制作中，关于这块如果有实操和疑问可以先直接 1v1 咨询小P」。编辑模式下可以直接改标题、介绍、示例图片和课程链接。没有示例时，界面上不显示「看看示例」按钮。`用AI：生图+调用API` 这一课会显示 生图 / 生视频 / 转文字 三个课程按钮。学习地图下方收起时只有一个带轮廓的小眼睛按钮，不显示黑条；点开后展开为和地图同宽的黑卡，里面是 AI行业发展 / AI政策趋势 / AI学术学科 / 更多 AI 探索 四个板块，点板块只在它自己下面下拉具体类目和「前往探索」，不影响地图本身的排版。
- **学习**：以个人学习地图为主体；页面最下方把「课程库」「能力测试」「海上餐厅」放在同一组，课程库在最上面。三张卡统一为透明底 + 绿色细边框，点击课程库这一条展开 AI工具课 / AI思维课 / AI应用课 / AI视野课 四类。28 门课程按四类归组，不显示课程数量；左侧切换类目、右侧看这个类目解决什么问题、能帮你什么；再点标题收起。课程库右上角「前往」打开总链接。类目介绍和「这个板块能帮你」可以在设置 → 编辑模式里改。
- **能力测试**：独立页面，一次只看一道题，共 24 题；技能线（工具 / 接口 / 智能体）、思维线（场景 / 资源 / 数据）、结果线（目标 / 交付 / 推进）。完成后进入独立 
eport.html，对照学习地图的结果层级给出建议起点、能力门槛和下一步。报告按浏览器本机保存。
- **顶部导航**：学习 / 赋能 / 交流 / 关于都是独立页面，学习放最左边；点击直接进入，不再先到首页再向下滚动；切换时统一使用横向滑动过渡（`page-transition.js` 处理，点击后立即跳转，新页面从右侧滑入；`file://` 和本地服务都生效）。页面之间也做了 prefetch，减少等待。
- **深度交流**：成员名片目录、标签筛选、搜索和申请交换弹窗。
- **右上角设置**：切换亮色 / 暗色，进入编辑模式，导出 / 导入文字修改（首页 / 赋能 / 关于支持）；底部有「检查更新」，会清除旧缓存并带版本号重新加载，不会删除文字修改。发布新版本时，把 `version.json`、页面资源版本号和 `assets/js/update.js` 的 `BUILD` 改成同一个版本号即可。

## 课程库 / 交流数据

- **课程库**：`route.html` 用个人学习地图和可收起的课程库展示 28 门课；课程库按 AI工具课 / AI思维课 / AI应用课 / AI视野课 分类说明功能并列出课程链接，链接直接来自研习社课程库（小鹅通），右上角可前往总链接。
- **交流申请**：`exchange.html` 的申请弹窗目前只把数据保存在浏览器本机；真实上线需要后端和通知服务。
- **成员档案**：示例数据在 `assets/js/members.js`，按同样字段替换成真实成员即可。手机号只用于匹配，不要渲染到公开卡片上。
- **成员申请**：当前只保存在浏览器本地；正式上线需要接后台审核和数据库。

## 怎么改内容

只改文字：用上面的「编辑文案」就够了。

要新增方案、改分类、改链接、换图，才需要动 `assets/js/data.js`。所有方案信息都在 `CASES` 数组里，一个对象就是一个方案：

```js
{
  id: 'growth',                 // 唯一标识，卡片和弹窗都用它
  index: '01',                  // 展示编号
  title: '赋能你的时间管理、目标管理、行动计划',
  subtitle: '一句话副标题',
  category: 'personal',         // personal / company / content / tool
  categoryName: '个人系统',
  year: '2026.08 — 2026.10',
  form: '网页应用 · 单文件',
  status: 'online',             // online 可在线体验 / external 外部链接 / local 本地应用
  statusText: '可在线体验',
  accent: '#f59e0b',
  cover: 'assets/img/xxx.jpg',  // 卡片封面
  gallery: ['...', '...'],      // 详情页预览图
  demo: 'demo/xxx.html',        // 有就出现「在线体验」标签页；没有留空
  external: 'https://...',      // 外部链接（可选）
  summary: '卡片上的一段话',
  description: '详情页正文，用 \\n\\n 分段',
  iterations: [                 // 迭代路径（详情页里展示）
    { v: '1.0', t: '起点', meta: '35 KB', d: '第一版做了什么。' },
    { v: '15.1', t: '现在', meta: '546 KB', d: '现在做到了什么。' }
  ],
  highlights: [{ t: '标题', d: '说明' }],
  stats: [{ k: '46', v: '个版本' }],
  stack: ['原生 JS', 'DeepSeek API'],
  quote: '一句总结'
}
```

新增方案：把截图放进 `assets/img/`，Demo 放进 `demo/`，然后在 `CASES` 末尾追加一个对象即可，筛选计数、详情页、「N 阶段」和「上一个 / 下一个」都会自动更新。

### 换主题色

打开 `assets/css/site.css`，最上面 `:root` 里的 `--lime` 就是那个荧光绿（默认 `#C9F14F`），`--bg` 是纸底色。深色主题在 `[data-theme="dark"]` 里改。
